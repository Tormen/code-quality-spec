# code-quality-spec

A portable, model-agnostic specification that an AI coding agent turns
into memories (rules it applies while writing), hooks (gates its harness
enforces) and tests (checks a project's own suite runs) -- so that the
code it produces is simpler, and does what it says.

Status: being written. Nothing here is final yet.
